# Android: предупреждение Play Protect «опасное приложение»

## Что реально происходит

Проверено через adb на Xiaomi 23124RN87C (Android 15, HyperOS 2):

1. APK открыт системным установщиком (`com.google.android.packageinstaller`).
2. Play Protect показал «Рекомендуется проверка приложения».
3. После нажатия «Проверить» появилось **«Вредоносное приложение
   заблокировано»** и «Это приложение может быть опасным».

Это вердикт **Google Play Protect**, а не ошибка подписи и не проверка MIUI.
APK 0.4.8 подписан release-сертификатом `CN=ProtoGrid, OU=Android Release,
O=ProtoGrid, C=RU`; `android:debuggable` отсутствует.

## Текущее состояние в репозитории

Возвращено поведение 0.4.9: встроенный загрузчик/установщик APK удалён,
`REQUEST_INSTALL_PACKAGES` и `FileProvider` (`res/xml/file_paths.xml`) удалены,
а кнопка обновления открывает `https://github.com/GimmickFive/ProtoGrid/releases/latest`.
То есть «VPN + установка APK» снова не образует dropper-профиль, и вердикт
«Вредоносное приложение заблокировано» из-за встроенного установщика уходит.
Остаётся только стартовый диалог Play Protect для APK, который Google ещё не
видел (см. ниже).

## Почему Play Protect это делает

Приложение распространяется вне Google Play, а его APK 0.4.8 умел:

- скачивать APK с GitHub и запускать установщик (`REQUEST_INSTALL_PACKAGES`,
  `FileProvider`, встроенный updater);
- видеть все установленные пакеты (`QUERY_ALL_PACKAGES`) для per-app VPN;
- поднимать VPN/прокси-туннель.

Связка «VPN + скачивание и установка APK» для эвристик Play Protect выглядит
как dropper/riskware. Это не значит, что в коде есть malware, но вердикт
принимается по поведению и репутации, а не по исходникам.

## Что изменено в 0.4.9

- Удалён встроенный установщик APK.
- Удалено разрешение `REQUEST_INSTALL_PACKAGES`.
- Удалён `FileProvider` и `res/xml/file_paths.xml`.
- Кнопка обновления теперь открывает страницу релиза в браузере; скачивание и
  установка — вручную через системный установщик.

### Результат проверки 0.4.9

Проверено на том же устройстве через системный установщик:

- Play Protect после «Проверить»: **«Судя по всему, приложение безопасное.
  Вы можете установить его»**.
- Встроенная проверка Xiaomi после установки: **«Угрозы не обнаружены»**,
  «Вирусы не найдены», «Приложение является легитимным».

Вердикт «Вредоносное приложение заблокировано» у 0.4.8 был связан именно с
встроенным установщиком APK/`REQUEST_INSTALL_PACKAGES`. После его удаления
блокировка ушла.

В 0.4.10 скачивание APK из приложения вернули **без**
`REQUEST_INSTALL_PACKAGES`. Проверка показала, что так системный установщик
запускается и сразу закрывается: разрешение действительно нужно для передачи
APK установщику.

В 0.4.11 `REQUEST_INSTALL_PACKAGES` возвращён, и обновление из приложения
снова доходит до установщика. Но проверка 0.4.11 сканером снова дала
**«Вредоносное приложение заблокировано»**: для Play Protect связка
«VPN + установка APK» остаётся dropper-профилем.

Итог: **одновременно «обновление из приложения» и «чистый Play Protect»
для sideload-сборки невозможны**. Варианты:

- **0.4.9** — без встроенного установщика, Play Protect чистый, обновление
  через браузер/GitHub.
- **0.4.11+** — обновление из приложения работает, но установку через
  системный установщик Play Protect блокирует. Обычный `adb install` 0.4.11
  тоже падает с `INSTALL_FAILED_VERIFICATION_FAILURE`; помогает временное
  отключение проверки adb-установок:
  ```bash
  adb shell settings put global verifier_verify_adb_installs 0
  adb install -r ProtoGrid-0.4.11-lite-arm64-v8a.apk
  adb shell settings put global verifier_verify_adb_installs 1
  ```
  После установки настройку можно вернуть обратно.
- **Play/RuStore/F-Droid** — единственный способ получить и удобные
  обновления, и отсутствие предупреждения.

Остаётся стартовый диалог Play Protect «Рекомендуется проверка приложения»
для APK, который Google ещё не видел. После «Проверить» он пропускает
установку. Этот диалог — не вердикт «опасное приложение»; полностью убрать его
для свежего sideload-APK нельзя. Варианты без диалога: `adb install` или
отключение проверки Play Protect на устройстве.

## Как установить сейчас

- Через adb — этот путь Play Protect не проверяет:
  ```bash
  adb install -r ProtoGrid-<версия>-lite-arm64-v8a.apk
  ```
- Через системный установщик: «Подробнее» → **«Установить без проверки»**.
- Полностью убрать диалог на устройстве: Play Маркет → профиль → Play Защита →
  шестерёнка → отключить «Проверять приложения с помощью Play Защиты». Это
  снижает защиту устройства, поэтому не рекомендуется как постоянное решение.

## Что нельзя исправить кодом

- Нельзя заставить Play Protect доверять APK вне Play.
- Нельзя «подписать» приложение так, чтобы проверка автоматически проходила.
- `adb install` обходит UI проверки, но не делает приложение доверенным для
  будущих установок через установщик.
