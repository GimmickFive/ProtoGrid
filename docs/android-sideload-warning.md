# Android: предупреждение «опасное приложение» при обновлении

## Симптом

При установке/обновлении APK из GitHub HyperOS (MIUI) или Google Play Protect
показывает предупреждение об опасном/непроверенном приложении. Установка
продолжается только после «Подробнее → Всё равно установить» или отключения
проверки.

## Что уже проверено

- APK **не debug**: подпись `CN=ProtoGrid, OU=Android Release, O=ProtoGrid, C=RU`,
  SHA-256 `e2f8fb5f...a9b78` (проверено `apksigner verify --print-certs`).
- `android:debuggable` отсутствует; targetSdk 35.
- Подпись стабильная, lineage-ротация настроена, обновление поверх 0.4.x не
  требует удаления приложения.
- В манифесте есть чувствительные для эвристик разрешения:
  - `REQUEST_INSTALL_PACKAGES` — встроенное обновление APK;
  - `QUERY_ALL_PACKAGES` — список приложений для per-app VPN;
  - `BIND_VPN_SERVICE`/VPN — сам туннель;
  - `CAMERA` — QR-сканирование;
  - `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`.

Предупреждение — это эвристика системы/Play Protect для приложений вне Play,
а не признак неправильной подписи или ошибки сборки. Полностью убрать его
средствами приложения нельзя.

## Варианты

1. **Оставить как есть и объяснить установку.**  
   В релизе/README: «Приложение распространяется вне Google Play, поэтому
   система может предупредить. Скачивайте только с GitHub-релиза и
   устанавливайте через “Всё равно установить”». Минус: предупреждение
   остаётся.

2. **Убрать `REQUEST_INSTALL_PACKAGES` и встроенную установку APK.**  
   Вместо скачивания и запуска установщика открывать страницу релиза в
   браузере. Это убирает одно из самых раздражающих разрешений и часть
   эвристик MIUI, но обновление становится ручным. Кандидат для 0.5.

3. **Убрать `QUERY_ALL_PACKAGES`.**  
   Список приложений станет неполным (Android 11+ скрывает часть пакетов),
   per-app VPN сломается. Не рекомендуется.

4. **Публикация в Play / F-Droid / RuStore.**  
   Доверенный магазин снимает предупреждение для своей установки, но требует
   модерации, политики VPN и отдельной сборки. Долгосрочный путь.

5. **Не распространять debug-сборки.**  
   Уже выполнено: релизы подписаны release-ключом, CI проверяет сертификат и
   падает на `CN=Android Debug`.
